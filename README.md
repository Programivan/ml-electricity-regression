# Практична робота: Машинне навчання (Лінійна регресія)
## Тема: Прогнозування споживання електроенергії в районі міста

Цей проєкт виконано в рамках курсу **«Creating AI Applications Using Python»** (IT STEP Academy).

---

## 📋 Опис завдань

### Завдання 1:
Побудувати модель лінійної регресії (`LinearRegression`), яка передбачає обсяг споживаної електроенергії (`consumption`, кВт·год) на основі даних:
- `temperature` — температура повітря (°C)
- `humidity` — вологість (%)
- `hour` — година доби (0–23)
- `is_weekend` — чи є день вихідним (0 або 1)

**Вимоги:**
- Побудувати графік **«Справжня vs Прогнозована ціна/споживання»**.
- Розрахувати відсоток помилки (**MAPE**) та інші метрики (MAE, RMSE, $R^2$).

### *Завдання 2 (додаткове):
Розширити модель властивостями району:
- `season` — пора року (`winter`, `summer`, `autumn`, `spring`)
- `district_type` — тип району (`industrial`, `residential`, `commercial`)
- Застосувати кодування категоріальних ознак за допомогою **`OneHotEncoder`** з бібліотеки `scikit-learn`.
- Проаналізувати покращення якості прогнозування.

## 🔍 Аналіз коефіцієнтів моделі (Завдання 2)

- **`district_type_Industrial` (+137.06 кВт·год)**: Промислові райони споживають значно більше електроенергії для виробництва та обладнання.
- **`district_type_Residential` (-133.47 кВт·год)**: Житлові райони споживають значно менше в порівнянні з комерційними та індустріальними.
- **`season_Winter` (-157.82 кВт·год)**: Суттєвий сезонний зсув у порівнянні з іншими сезонами.
- **`temperature` (+5.07 кВт·год)**: При зростанні температури споживання зростає (активне кондиціонування).
- **`hour` (+4.20 кВт·год)**: В денний та вечірній час навантаження вище.

## 🚀 Інструкція із запуску

### 1. Створення та активація віртуального середовища
```bash
# Створення
python -m venv .venv

# Активація (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Активація (Windows CMD)
.venv\Scripts\activate.bat

# Активація (Linux / macOS)
source .venv/bin/activate
```

### 2. Встановлення бібліотек
```bash
pip install -r requirements.txt
```
*(Або `pip install numpy pandas matplotlib seaborn scikit-learn`)*

### 3. Запуск коду
- **Запуск обох завдань:**
  ```bash
  python main.py
  ```
- **Запуск окремо:**
  ```bash
  python task1.py
  python task2.py
  ```
- **Відкриття Jupyter Notebook:**
  ```bash
  jupyter notebook solution.ipynb
  ```
